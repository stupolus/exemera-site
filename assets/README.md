## Как заменить любое фото

Положите новый файл с тем же именем — сайт подхватит его без правки кода.
Если файл убрать, на его месте появится стильная заглушка (не «битая» картинка).

Рекомендации: JPG шириной 1600–2400 px, вес до ~500 КБ (sквиз — squoosh.app).
Видео: MP4 (H.264 + AAC), для веба достаточно 1080p.
